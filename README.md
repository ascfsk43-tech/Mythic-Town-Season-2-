# متجر Mythic Town Season 2

## التشغيل
1. ثبّت Node.js (الإصدار 16 أو أحدث) من https://nodejs.org
2. افتح الطرفية داخل هذا المجلد وشغّل:
   node server.js
3. افتح http://localhost:3000

لا يحتاج أي مكتبات ولا npm install.
المنفذ يتغير بـ PORT، مثال: PORT=8080 node server.js

## الأدمن
- اضغط أيقونة القفل في أعلى الصفحة.
- كلمة المرور الافتراضية: admin123 (غيّرها فوراً من الإعدادات، أو شغّل السيرفر بـ ADMIN_PASSWORD=كلمتك قبل أول تشغيل).
- من شريط الأدمن: إضافة منتج، تعديل الاسم والسعر والوصف والصورة، الطلبات (وتغيير حالتها)، السجلات، الإعدادات.

## أين يُحفظ كل شيء (كله ملفات)
- data/products.json  المنتجات
- data/settings.json  الإعدادات وكلمة مرور الأدمن (مشفّرة)
- data/orders.json    الطلبات
- logs/orders.log     سجل كل طلب
- logs/admin.log      سجل الأدمن: دخول، محاولات فاشلة، إضافة/تعديل/حذف، تغيير حالة طلب
- logs/server.log     تشغيل السيرفر والأخطاء
- public/uploads/     صور المنتجات المرفوعة
نسخة احتياطية = انسخ مجلدات data و logs و public/uploads.

## الطلبات على ديسكورد (اختياري)
أنشئ Webhook في قناة ديسكورد (إعدادات القناة > التكاملات > Webhooks)، والصق الرابط في إعدادات المتجر. كل طلب جديد يصل للقناة تلقائياً.

## الاستضافة
ارفع المجلد كاملاً على أي استضافة تدعم Node.js (VPS، Render، Railway...) وشغّل node server.js.
- استخدم HTTPS من الاستضافة، لأن كلمة مرور الأدمن تُرسل عبر الشبكة.
- خلف Nginx أو Cloudflare شغّل بـ TRUST_PROXY=1 لتظهر IP الحقيقية في السجلات.
- السيرفر يحمي الدخول: 5 محاولات فاشلة تحظر الـ IP عشر دقائق، والطلبات محدودة بـ 6 في الدقيقة لكل IP، والأسعار تُحسب في السيرفر ولا يمكن تعديلها من المتصفح.

## بدون سيرفر
لو فتحت public/index.html مباشرة بالمتصفح يعمل بوضع محلي: كل شيء يُحفظ في متصفحك أنت فقط ولا يراه الزوار. للاستخدام الفعلي شغّل server.js.
